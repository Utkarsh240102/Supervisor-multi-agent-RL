# Victoria SCATS Real-World Benchmark Graphs

This folder contains all high-resolution (300 DPI) standalone publication charts generated from the empirical Transport Victoria SCATS Site 4012 evaluation across all 7 architectural phases.

## File Guide

1. **`throughput_comparison_all_phases.png`**  
   * Dedicated standalone graph comparing **Throughput (Completed Trips per Hour)** across all 7 Phases (with exact numerical bar labels and highlight annotations for $+15\%$ cooperative gain & highest 8-intersection flow).

2. **`fig1_throughput_all_phases.png`**  
   * Complete 7-Phase Throughput comparison bar chart.

3. **`fig2_waiting_time_all_phases.png`**  
   * Complete 7-Phase 60-Minute Average Waiting Time comparison (illustrating the **88.4% delay reduction**).

4. **`fig3_halting_queue_all_phases.png`**  
   * Complete 7-Phase Average Halting Queue per Intersection comparison.

5. **`fig4_single_inter_ddqn_vs_baseline.png`**  
   * Focused comparison: **Phase 0 (Single Intersection — Fixed Time vs Single Agent DDQN)**.

6. **`fig5_4inter_cooperative_gain.png`**  
   * Focused comparison: **Phase 1 (4-Intersection Grid — Independent vs Cooperative DDQN)** showing the **+15.0% throughput gain**.

7. **`fig6_8inter_supervisor_hierarchy.png`**  
   * Focused comparison: **Phase 2 (8-Intersection Grid — Independent vs Supervisor No Comm vs Supervisor With Comm)** showing the **+31.3 trip boost**.

8. **`fig7_scats_radar_comparison.png`**  
   * Multi-Metric Radar Chart comparing overall performance across Throughput, Low Wait Time, Low Queue, and Stability.
